# Бурундук

Локально запускаемый мессенджер с аккаунтами, личными сообщениями по WebSocket и аудио-/видеозвонками WebRTC. В базе нет тестовых пользователей: контакты появляются только после регистрации реальных аккаунтов и добавления по никнейму.

## Запуск

Нужен Node.js 20 или новее.

```sh
npm install
npm start
```

Откройте `http://localhost:3000`. Для проверки общения создайте два аккаунта в разных браузерах или профилях, затем добавьте точный никнейм второго пользователя в контакты.

Пользователи и история сообщений хранятся в `data/messenger.json`. Пароли хранятся в виде хешей scrypt. Токены входа действуют до перезапуска сервера.

В профиле можно выбрать животное-эмодзи для аватара. Выбор сохраняется на сервере и показывается в списке контактов и переписке.

## Уведомления и звук

Новые сообщения и входящие звонки показывают уведомление в приложении. Для сообщений и приглашений на звонок поддерживаются системные Web Push-уведомления, в том числе когда приложение закрыто. Нажатие на push о звонке открывает чат для обратного вызова: ответить на звонок и продолжить WebRTC-разговор можно только когда приложение открыто и подключено. Кнопка «Уведомления» запрашивает разрешение и подключает устройство; выключение удаляет его push-подписку. Звуки генерируются браузером; после входа звук разблокируется первым действием пользователя.

Для системных и фоновых уведомлений сервер должен быть доступен по HTTPS, работать постоянно и иметь доступ к push-сервисам браузера. На телефоне `localhost` на компьютере не подходит: нужен HTTPS-адрес. Разрешите уведомления в настройках сайта; если браузер уже блокировал их, измените разрешение вручную и снова включите уведомления в приложении. Если Service Worker не запускается, закройте лишние вкладки сайта; в Chrome/Edge откройте DevTools → Application → Service Workers → Unregister, обновите страницу и настройте уведомления повторно. VAPID-ключи создаются автоматически и хранятся в `data/vapid-keys.json`; сохраните этот файл при переносе сервера и не публикуйте его. Для production задайте `VAPID_SUBJECT` в формате `mailto:адрес-оператора@example.com`.

На Android откройте HTTPS-адрес в Chrome, разрешите уведомления и при желании добавьте сайт на главный экран через меню браузера. На iPhone/iPad Web Push доступен в iOS 16.4+ для сайта, добавленного на экран «Домой» и запущенного как веб-приложение. Push о звонке — это баннер-приглашение, а не работающий в фоне звонок: чтобы поговорить, откройте чат и перезвоните.

## Звонки и публикация

Звонки передают сигнал WebRTC через WebSocket и соединяют браузеры напрямую. Доступ к микрофону и камере требует `localhost` или HTTPS. STUN помогает установить соединение; для сетей, где прямое соединение невозможно, задайте TURN-сервер:

- `TURN_URL` — адрес TURN-сервера;
- `TURN_USERNAME` — имя пользователя;
- `TURN_CREDENTIAL` — пароль или выданные провайдером учётные данные.

Для доступа из интернета разверните сервер за HTTPS/WSS reverse proxy и настройте TURN. Не публикуйте сервер с HTTP в открытом интернете: для production также потребуются HTTPS, резервное копирование, ограничение частоты запросов и управляемое хранилище.

Сообщения в этой версии не имеют сквозного шифрования: сервер может их прочитать.
