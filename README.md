# Бурундук

Локально запускаемый мессенджер с аккаунтами, личными сообщениями по WebSocket и аудио-/видеозвонками WebRTC. В базе нет тестовых пользователей: контакты появляются только после регистрации реальных аккаунтов и добавления по никнейму.

## Запуск

Нужен Node.js 20 или новее.

```sh
npm install
npm start
```

Откройте `http://localhost:3000`. Для проверки общения создайте два аккаунта в разных браузерах или профилях, затем добавьте точный никнейм второго пользователя в контакты.

Пользователи и история сообщений хранятся в `data/messenger.json`. Пароли хранятся в виде хешей scrypt. Токены входа действуют до перезапуска сервера.

## Уведомления и звук

Новые сообщения и входящие звонки показывают уведомление в приложении. Если вкладка скрыта, браузер также покажет системное уведомление при выданном разрешении. Кнопки «Уведомления» и «Звук» в боковой панели позволяют настроить оповещения. Звуки генерируются браузером; после входа звук разблокируется первым действием пользователя.

Уведомления приходят, пока приложение открыто и подключено к серверу. Для работы системных уведомлений браузер должен разрешить их для сайта.

## Звонки и публикация

Звонки передают сигнал WebRTC через WebSocket и соединяют браузеры напрямую. Доступ к микрофону и камере требует `localhost` или HTTPS. STUN помогает установить соединение; для сетей, где прямое соединение невозможно, задайте TURN-сервер:

- `TURN_URL` — адрес TURN-сервера;
- `TURN_USERNAME` — имя пользователя;
- `TURN_CREDENTIAL` — пароль или выданные провайдером учётные данные.

Для доступа из интернета разверните сервер за HTTPS/WSS reverse proxy и настройте TURN. Не публикуйте сервер с HTTP в открытом интернете: для production также потребуются HTTPS, резервное копирование, ограничение частоты запросов и управляемое хранилище.

Сообщения в этой версии не имеют сквозного шифрования: сервер может их прочитать.
